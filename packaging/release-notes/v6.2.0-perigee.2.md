Perigee is an independent remote desktop and game-streaming client based on Moonlight Qt. It supports Apollo and standard Sunshine. Perigee keeps its settings and pairing identity separate from Moonlight.

## What's new since 6.2.0-perigee.1

- **Windows packages.** Perigee now builds for Windows 10 and 11 on x64 and ARM64, with an installer and portable zips. Windows uses its own settings and never shares pairing with an installed Moonlight.
- **Fedora 45 on ARM64.** A native aarch64 RPM is now built alongside the x86_64 RPMs.
- **GNOME-style look.** The interface follows the GNOME/libadwaita style, with a flat header bar, rounded cards and preference groups, and uses Adwaita Sans or Cantarell when installed.
- **Floating profile button.** The computer and app pages show a floating button to see and switch the session profile.

The Flatpak and AppImage from [6.2.0-perigee.1](https://github.com/BarMy49/perigee/releases/tag/v6.2.0-perigee.1) are not rebuilt for this release.

## Status

This is an unsigned prerelease. Windows may show a SmartScreen warning. The RPMs pass install, verification, startup and removal checks in their Fedora build containers, and the Windows packages pass CI build and identity checks. Live streaming checks on the new GNOME-style interface, on ARM64 and on real Windows PCs are still pending. Moonlight import remains Linux-only.
