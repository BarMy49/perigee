Perigee is an independent remote desktop and game-streaming client based on Moonlight Qt. It supports Apollo and standard Sunshine. Perigee keeps its settings and pairing identity separate from Moonlight.

This release catches up with upstream [Moonlight Qt](https://github.com/moonlight-stream/moonlight-qt). It brings in the 50 upstream changes made since Perigee forked, on top of [7.0.1](https://github.com/BarMy49/perigee/releases/tag/v7.0.1).

## What's new since 7.0.1

- **Steadier streaming core.** The streaming library (moonlight-common-c) is updated with about 55 stability fixes, including race fixes in video, input and timing, sturdier STUN and RTSP handling, and correct setup when you start a second stream.
- **Video renderer fixes.** VAAPI, Vulkan, CUDA and D3D11 decoding get upstream fixes, along with better V-Sync waiting and dropped-frame counting.
- **Audio recovers on its own.** If audio output fails during a stream, it now restarts instead of going silent.
- **Sturdier gamepads.** Gamepad and haptics handling picks up upstream fixes.
- **Pairing fix.** An upstream fix to how pairing keys are handled is included, and a PIN given on the command line must now have 4 digits.
- **Newer Windows dependencies.** Windows builds use Qt 6.12.1, upstream's newer prebuilt libraries and the latest MSVC runtime.
- **libplacebo update.** The bundled libplacebo used by the Vulkan renderer is bumped to v7.387.0 in the AppImage and Flatpak recipes. Those builds are not published for 7.x yet, and the RPMs use Fedora's own libplacebo.

Matching Fedora source RPMs are included. Verify downloads with **sha256sum --check --ignore-missing SHA256SUMS**. All packages are built in GitHub Actions from the commit this release is tagged on. Settings and pairing carry over from 7.0.1.

## Status

The packages are unsigned, so Windows may show a SmartScreen warning. The RPMs pass install, verification, startup and removal checks in their Fedora build containers, and the Windows packages pass CI build and identity checks. Live streaming checks on real Windows PCs and on ARM64 are still pending. Moonlight import remains Linux-only.
