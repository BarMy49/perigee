Perigee is an independent remote desktop and game-streaming client based on Moonlight Qt. It supports Apollo and standard Sunshine. Perigee keeps its settings and pairing identity separate from Moonlight.

This is a small patch release on top of [7.0.0](https://github.com/BarMy49/perigee/releases/tag/v7.0.0).

## What's new since 7.0.0

- **Session profiles keep your changes.** Choosing Programming or Gaming now loads that profile's settings. While a profile is selected, any setting you change is saved to it, so it is still there the next time you pick that profile. **Current settings** keeps the values you have without a profile.
- **Command-line streams match the app.** Streams started from the command line now begin from your current settings, including the selected profile. Command-line options still override them.
- **Existing profiles carry over.** On first start, a saved profile keeps the settings it last streamed with.

Matching Fedora source RPMs are included. Verify downloads with **sha256sum --check --ignore-missing SHA256SUMS**. All packages are built in GitHub Actions from the commit this release is tagged on. Settings and pairing carry over from 7.0.0.

## Status

The packages are unsigned, so Windows may show a SmartScreen warning. The RPMs pass install, verification, startup and removal checks in their Fedora build containers, and the Windows packages pass CI build and identity checks. Live streaming checks on real Windows PCs and on ARM64 are still pending. Moonlight import remains Linux-only.
