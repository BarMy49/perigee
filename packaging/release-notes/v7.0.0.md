Perigee is an independent remote desktop and game-streaming client based on Moonlight Qt. It supports Apollo and standard Sunshine. Perigee keeps its settings and pairing identity separate from Moonlight.

> **Note:** Not much has changed since [6.2.0-perigee.2](https://github.com/BarMy49/perigee/releases/tag/v6.2.0-perigee.2). The jump to 7.0 is mainly there to clean up how releases are named. From now on, Perigee releases use plain version numbers such as v7.0.0 instead of the upstream Moonlight version with a -perigee suffix.

## What's new since 6.2.0-perigee.2

- **Easier to read.** Buttons, menus and settings use sentence case instead of all caps. Settings descriptions are larger and easier to read, and preference groups have more room between them.
- **Clearer computer list.** Each computer card shows whether it is Online, Offline or Unpaired, and the cards are more compact. An empty list now shows a hint and an "Add PC manually" button.

Matching Fedora source RPMs are included. Verify downloads with **sha256sum --check --ignore-missing SHA256SUMS**. All packages are built in GitHub Actions from the commit this release is tagged on. Settings and pairing carry over from 6.2.0 builds.

## Status

The packages are unsigned, so Windows may show a SmartScreen warning. The RPMs pass install, verification, startup and removal checks in their Fedora build containers, and the Windows packages pass CI build and identity checks. Live streaming checks on real Windows PCs and on ARM64 are still pending. Moonlight import remains Linux-only.
